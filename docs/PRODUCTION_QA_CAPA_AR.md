# Production QA / CAPA

- Production Lot يجب أن يشير إلى Production Release.
- QC check: OPEN / PASS / FAIL.
- Defect severity: MINOR / MAJOR / CRITICAL.
- MAJOR/CRITICAL المفتوح يمنع الإفراج.
- حل defect يحتاج Corrective Action موثق.
- Lot Release يحتاج QC evidence وكل QC PASS ولا Major/Critical مفتوح.
