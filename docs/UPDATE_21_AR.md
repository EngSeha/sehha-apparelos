# Preview 21 — Full Actual Cost

تم استكمال التسوية الفعلية من Material-only إلى تكلفة إنتاج فعلية كاملة عند تفعيل المسار صراحة.

- Actual Material: من Reconciliation.
- Actual Labor: minutes + hourly rate لكل عملية تشغيل.
- Actual Overhead: مبلغ صريح.
- Actual Total + Cost/Good Unit + Total Variance.
- لا يتم افتراض أي أرقام أو تحويل عملات.
