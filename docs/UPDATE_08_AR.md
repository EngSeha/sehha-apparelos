# SEHHA ApparelOS — Update 08

Preview 08 يحول الـMOHSEN/NEXZ 20P Master إلى **Dynamic Garment Template Engine**.

## الجديد

- Garment Template Profile Registry.
- 20P renderer garment-agnostic.
- Dynamic cover garment identity.
- Code-agnostic POM pages.
- Dynamic Pattern Cut Cards.
- Dynamic Special Construction Detail.
- Garment-agnostic Template Completeness.
- New Style dialog يعتمد Garment Profiles من backend.
- Output Template `mohsen_nexz_20p` أصبح v2 ويعلن `garmentAgnostic=true`.

## لا يوجد Schema Migration

Preview 08 يستخدم نفس schema 8؛ التغيير في منطق الـRenderer والـTemplate Registry والواجهة والاختبارات فقط.
